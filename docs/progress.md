- PWA: `app/manifest.ts`, PNG icons generated by `scripts/make-icons.ts` (headless Chromium), `public/sw.js` (app shell + `/offline` fallback, no API caching), registered in production only.
- Tab bar shell (Today, Week, Food, Body, Shop), Settings (targets table, passkeys, sign out, About with the Livsmedelsverket credit), `/api/health`.
- Tests: Vitest for `lib/rules/time.ts` (DST weeks in March 2027 and October 2026), Playwright smoke (`tests/e2e/foundation.spec.ts`).

## Decisions

- **Toggle after logging.** Switching the Tuesday-frisbee template keeps statuses for sessions that stay on the same date. Done sessions the new template no longer has are kept as extra rows (so the week can show two sessions on a day) and the toggle reports it. Spec is silent on this.
- **Moving a session** marks the original `moved` (with `moved_to_date`) and plans a copy on the target date; Undo removes the copy. The spec's "Moved" status is kept as the audit trail.
- **Walk and rest are not "sessions"** in the Week summary, matching the mockup's "2 of 5".
- **Gym A / Gym B times.** The seed has no time for Gym A (lunch or evening) and 11:00 for Gym B; the Week row shows "Lunch" for Gym A like the mockup.

- **Passkeys in their own table.** The spec lists credentials under `users`; `passkey_credentials` holds one row per device instead.
- **Day-type override table.** The spec says the user can override the day type by hand but lists no table; `day_type_overrides(date, day_type)` is the 31st table.
- **Magic-link fallback deferred.** It needs `EMAIL_SERVER`; it ships with the email/push work in Milestone 6. Until then, register a second passkey from Settings as the recovery path.
- **Service worker.** Next 16 builds with Turbopack and `@serwist/next` is a webpack plugin, so Milestone 1 ships a small hand-written worker. Milestone 6 decides between Serwist and extending it.
- **Dependencies beyond the spec:** `postgres` (driver), `@simplewebauthn/server|browser`, `jose`, `tsx`, `@fontsource-variable/inter|space-grotesk` (Google Fonts are not reachable from the build environment, and self-hosting suits an offline PWA). shadcn pulled in `@base-ui/react`, `cn`, `tw-animate-css`, `class-variance-authority`, `clsx`, `tailwind-merge`, `lucide-react`.
- **Number formatting** follows the mockups (`2,400`), not Swedish grouping.
- The handoff README is kept as `docs/HANDOFF.md`; the root README describes the app.
